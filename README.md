# Fall Game

It is a Game where you have to get as most as leaves you can get in the dustbin

## Description

It is a game where you have a bin in control and you catch all of the leaves with it every leaf gives you 1 score .this game is basically pretty simple and easy you use "A" for moving left , "D" for moving right and you catch the leaves
